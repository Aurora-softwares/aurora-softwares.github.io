**Quark IDE** is Aurora Softwares' development environment for Hydrogen projects. It's intended to bring the tools for editing, organising and building software into one friendly desktop workspace.

## What is an IDE?

An **integrated development environment** (IDE) is an application that helps you write code. Instead of switching between lots of tools, you can work with files and projects from one place.

Quark's focus is a native desktop experience alongside practical tools for Hydrogen.

## Where should I begin?

1. **Get to know the workspace.** Visit the [Quark documentation](https://aurora-softwares.github.io/Quark-Docs/) for introductory guides.
2. **Learn the language.** If you're new to Hydrogen, the [Hydrogen docs](https://hylang.co.uk/) explain the language and compiler.
3. **See what's changing.** The [Quark IDE repository](https://github.com/Aurora-softwares/Quark-IDE) tracks the application and development progress.

Quark is still under active development, so its interface and available features can change.

You can also [read the Quark project introduction](/work/quark/) on the company website.
