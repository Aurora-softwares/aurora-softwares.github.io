**Hydrogen** is Aurora Softwares' programming language. It is being designed to build software for multiple operating systems, with a compiler that is increasingly written in Hydrogen itself.

## What is a compiler?

A compiler turns the code you write into something your computer can run. Hydrogen's compiler aims to produce programs for Linux, Windows, macOS and, as the operating system develops, Australis OS.

Platform support is a work in progress. Some features may exist only in development builds, so always check the latest documentation before following a tutorial.

## Where should I start?

1. **Read the getting-started guide.** The [Hydrogen documentation](https://hylang.co.uk/) covers installation, writing your first program, language features and building projects.
2. **Explore the language.** Look at examples and language guides to learn how Hydrogen code is organised.
3. **Follow development.** The [Hydrogen compiler repository](https://github.com/Aurora-softwares/Hylang-Compiler) contains the source code and ongoing work.

## How does Hydrogen fit with the other projects?

[Quark IDE](/docs/projects/quark/) is being built as a desktop environment for writing Hydrogen. [Australis OS](/docs/projects/australis/) is a separate operating system that Hydrogen can target as the two projects develop.

You can also [read the Hydrogen project introduction](/work/hydrogen/) on the company website.
