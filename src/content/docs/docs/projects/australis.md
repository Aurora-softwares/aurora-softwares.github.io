**Australis OS** is an operating system being built from the ground up. Instead of starting with an existing operating system, the project tackles essential pieces including its kernel, file systems, drivers, graphics and applications.

## What does that mean?

An operating system is the software that makes a computer usable. It manages hardware and gives applications a way to do their work.

Australis is an **experimental, in-development project**, not a finished everyday replacement for Windows, macOS or Linux.

## Find your way around

The [Australis OS documentation](https://aurora-softwares.github.io/Australis-Docs/) is the best place to learn about its architecture and ongoing work.

- **Building the OS:** requirements and instructions for developers.
- **Architecture:** how the kernel and its subsystems fit together.
- **Graphics and applications:** progress towards a usable desktop environment.

The [Australis OS source repository](https://github.com/Aurora-softwares/Australis-OS) has the code and current development history.

## How does it connect to Hydrogen?

[Hydrogen](/docs/projects/hydrogen/) is Aurora's programming language and one of the technologies being developed alongside Australis. They are separate projects with a shared long-term goal.

You can also [read the Australis project introduction](/work/australisOS/) on the company website.
