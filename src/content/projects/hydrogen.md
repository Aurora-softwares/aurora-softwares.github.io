## Say hello to Hydrogen

Hydrogen is Aurora Softwares’ programming language project. Its goal is simple to explain: give developers a consistent way to write software for different operating systems.

The compiler is being developed in Hydrogen itself, a process called **self-hosting**. It’s an ongoing project, and platform support is being built out step by step.

## What can you explore?

- **The language:** learn the syntax, write programs and discover how projects are organised.
- **The compiler:** follow work on building and running native programs.
- **The future:** see how Hydrogen connects to Quark IDE and Australis OS.

## Find out more

For a practical introduction, start with the [Hydrogen documentation](https://hylang.co.uk/). For source code, changes and development progress, visit the [compiler on GitHub](https://github.com/Aurora-softwares/Hylang-Compiler).

Hydrogen is under active development. Check the documentation and repository for the latest supported platforms and features.
