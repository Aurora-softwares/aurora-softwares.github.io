Welcome! This is the documentation home for **Aurora Softwares**. Whether you are here to try something new, understand how a project works or follow its progress, you're in the right place.

We have three closely connected projects: a programming language, an operating system and an IDE (a place to write code). You don't need to be an expert to start exploring.

## What would you like to explore?

- **[Hydrogen](/docs/projects/hydrogen/)** — a programming language and compiler. Start here if you want to learn how to write or build programs.
- **[Australis OS](/docs/projects/australis/)** — an operating system built from the ground up. Start here if you're interested in operating systems and how they work.
- **[Quark IDE](/docs/projects/quark/)** — a desktop workspace for building Hydrogen projects. Start here if you're interested in the tools for writing software.

## How this documentation works

These short guides help you find your way. Each project also has its **own detailed documentation**, with instructions and more technical topics. You'll find a link to those docs on the project pages.

If you'd rather see the bigger picture first, [visit the Aurora homepage](/) or [browse the project showcase](/work/).

:::tip[Still deciding where to start?]
Think of it this way: **Hydrogen** is the language you write, **Quark** is where you write it, and **Australis OS** is an operating system that Hydrogen also aims to support.
:::

## Follow along

Everything here is evolving. Visit [Aurora Softwares on GitHub](https://github.com/Aurora-softwares) to see repositories, source code and development activity.
